## 0. לפני שמתחילים

1. **הטרמינל החי חייב להיות סגור.**
2. **ההכנה כבר בוצעה (`gui-prepare`):**
   - נשמר גיבוי של `common.ini`;
   - נכתבה תצורת הפעלה ללא חיבור: `Login=0`, ‏proxy לפורט סגור `127.0.0.1:9`, ו־`Enabled=0` / ‏`AllowLiveTrading=0`, כלומר המסחר האלגוריתמי כבוי.

## 1. הפעלת העותק המבודד בלבד

הריצו את הפקודה הזאת ב־PowerShell או ב־cmd. אל תשתמשו בקיצור הדרך שבשולחן העבודה:

```
"C:\mt5r\terminal64.exe" /portable /config:C:\mt5r\runs_ini\duka_gui.ini
```

**אחרי שהטרמינל עולה:**
- **אם נפתח חלון התחברות:** לחצו Cancel. אל תזינו חשבון או סיסמה.
- **בדקו את מצב החיבור בפינה הימנית התחתונה.** הוא צריך להראות שאין חיבור, למשל "No connection" או "Invalid account".
  - **אם מופיע חיבור עם ping:** סגרו את הטרמינל מיד, עצרו והודיעו לי.
- **אל תלחצו על Algo Trading,** אל תפתחו EA ואל תריצו סקריפט.

## 2. יצירת הסימבול. כל המאפיינים נקבעים לפני הייבוא

1. **פתחו את חלון הסימבולים:** ‏View → Symbols (‏Ctrl+U).
2. **לחצו Create Custom Symbol.**
3. **השאירו את השדה "Copy from" ריק.** אם תעתיקו מ־XAUUSD.s, ‏Digits יהיה 2 והספרה השלישית של המחיר תאבד.
4. **הזינו את המאפיינים:**

| מאפיין | ערך | הסבר |
|---|---|---|
| Symbol | `XAUUSD.duka` | השם שהבדיקות מצפות לו |
| Description | `Dukascopy XAU/USD ticks, UTC (data check)` | |
| **Digits** | **3** | מספר הספרות אחרי הנקודה. מ־Digits נגזר **Point** ‏= 10⁻³ ‏= **0.001**; ב־MT5 אין שדה Point נפרד |
| **Tick size** | **0.001** | צעד המחיר המינימלי. זה שדה נפרד מ־Digits: Digits=3 עם Tick size 0.01 היה מעגל את המחירים לצעד של סנט |
| Tick value | 0.1 | ‏0.001 × ‏100 אונקיות ‏= 0.1 USD לטיק, ללוט אחד |
| Contract size | 100 | |
| Calculation | CFD | |
| Currency base / profit / margin | XAU / USD / USD | אם XAU לא מופיע ברשימה, רשמו מה נבחר והודיעו לי |
| Chart mode | Bid | |
| Spread | Floating | |
| Stops level / Freeze level | 0 / 0 | |
| Volume min / step / max | 0.01 / 0.01 / 100 | |
| Sessions (Quotes ו־Trade) | 00:00–24:00 בכל 7 הימים | כדי שאף טיק לא יסונן לפי סשן. שעות המסחר האמיתיות נמדדות מהנתונים, בנפרד |

5. **אשרו ב־OK.**
6. **פתחו שוב את מאפייני `XAUUSD.duka` וודאו:** ‏Digits = 3, ‏Tick size = 0.001.
   - אם אחד מהם שונה, תקנו אותו **לפני** הייבוא.

## 3. ייבוא הטיקים

1. **בחלון Symbols:** בחרו את `XAUUSD.duka`, עברו ללשונית **Ticks** ולחצו **Import Ticks**.
2. **בחרו את הקובץ:** `D:\data\dukascopy\mt5_manual\XAUUSD.duka_20240102_1000_UTC_ticks.csv`.
3. **בחלון הייבוא:**
   - המפריד הוא Tab.
   - בתצוגה המקדימה העמודות הן Date, ‏Time, ‏Bid, ‏Ask, ‏Last, ‏Volume.
   - השורה הראשונה: `2024.01.02 10:00:00.128 2076.965 2077.255`. אם המילישניות או הספרה השלישית חסרות בתצוגה, עצרו ורשמו מה מוצג.
4. **אשרו את הייבוא.** לפי התיעוד, הייבוא מחליף את כל הנתונים בטווח הזמן של הקובץ.

## 4. קריאה חוזרת בממשק

1. **בלשונית Ticks של `XAUUSD.duka`:** בקשו את הטווח 2024.01.02 ‏10:00 עד 2024.01.02 ‏11:00. אם יש כפתור Request, לחצו עליו.
2. **ייצאו את הטיקים:** אם יש כפתור **Export Ticks**, שמרו את הקובץ בנתיב `D:\data\dukascopy\mt5_manual\readback_XAUUSD.duka_20240102_1000.csv`.
   - **אם אין כפתור ייצוא:** רשמו זאת והודיעו לי. הבדיקה תסתמך אז על הטסטר בלבד.
3. **רשמו את מספר הטיקים** שהממשק מציג, אם הוא מוצג.

2. **אל תפתחו גרפים ואל תצרפו EA.**

**אם הממשק לא מאפשר להתקדם בלי חיבור:** עצרו ותעדו מה הופיע. אל תתחברו.

## מה יקרה אחרי ההודעה שלכם

1. **`gui-finish`:**
   - שחזור `common.ini` מהגיבוי;
   - בדיקה שאין שורות חיבור ביומן של הסשן הזה בלבד;
   - רישום קובצי הסימבול שנוצרו.
2. **קריאה חוזרת:** קובץ הייצוא מושווה למקור טיק־מול־טיק: מספר, זמן במילישניות, Bid, ‏Ask וסדר.
3. **בדיקת טסטר עם EA האבחון `duka_tick_dump`,** שאינו פותח פקודות: אילו טיקים הטסטר מוסר בפועל, ומה המפרט של הסימבול.
4. **הדיווח יפריד בין שלושה דברים:**
   - הצלחת הייבוא: על פי ראיות בלבד;
   - התאמת הנתונים;
   - כיסוי התקופה: שעה אחת אינה כיסוי של חודש.
